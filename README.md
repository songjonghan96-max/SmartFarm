# 무병묘 스마트팜 MES Project

| **송종한** (Song Jong-han) - [Songjonghan96-max] 포트폴리오

## Intro

이 프로젝트는 스마트팜 환경에 최적화된 제조 실행 시스템 구축을 통한 생산 데이터 관리 및 공정 효율화를 목적으로 진행한 팀 프로젝트입니다.

### 수행 역할

* **기획 및 분석**
    * 관련 MES 시장 조사 및 차별점 파악, 구현에 필요한 기능 명세화
* **설계**
    * 스토리보드 작성 및 컬러 가이드북 제작, 시스템 아키텍처 및 개발 환경 표준화
* **데이터베이스**
    * UML 및 ERD 제작, DB 설계 규격서 작성
* **환경 구축**
    * Git 저장소 구성, 프로젝트 의존성 및 서버/DB 환경 설정
* **개발**
    * AI 머신러닝 활용 로스율 예측 시스템 개발
    * 자재, BOM, 공정, 입출고 페이지 구현, 페이징 및 공통 레이아웃 제작
